# VLM's Response to Misleading Clinical Information

### This is the GitHub for "The Impact of Misleading Clinical Information on Vision-Language Models and Human Experts in Medical Genetics"

### Scripts
Code for how we prompted and called different VLM's can be found in ``api_call_queries.py`` and ``call_medgemma.py``. Model names, image paths, and prompt paths may be modified within these scripts. The output .csv paths from these two scripts can be used as an input for the ``mixture_agents.py`` script. 
The prompts we used for the 100 publicly available images can be found in ``all_prompts.csv``.

### Image Datasets
The 100 publicly available images that were used in these experiments can be found in ``Images`` folder.

### Surveys
Four examples of surveys  we sent to participants can be found in the ``Surveys`` folder.
